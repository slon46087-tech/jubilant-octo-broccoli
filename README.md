# Standoff 2

## Сборка APK через GitHub Actions

1. Замените файл `Icon/icon.png` своей PNG-иконкой приложения. Во время сборки углы иконки автоматически закругляются.
2. Загрузите содержимое проекта в GitHub-репозиторий, сохранив структуру папок.
3. Откройте **Actions → Build Standoff 2 APK → Run workflow**.
4. После завершения скачайте артефакт **Standoff-2-APK**.

Workflow создаёт большой файл только во время сборки, поэтому сам репозиторий остаётся маленьким. Итоговый APK имеет размер примерно 2,75 ГБ.
